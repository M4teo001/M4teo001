## How this is built

A small operation, AI-native by design — and specific about what that means:

- **Product, architecture, direction** — me
- **Code execution** — Claude Code (Opus 5), with an internal skill and hook system that enforces our conventions
- **Every commit** — automated confidentiality guard, typecheck, and adversarial review before it lands
- **Operations** — we run on the same platform we sell

The trade-off is honest: every decision goes through one person, so there is no coordination overhead and no committee. That is why we ship in days. It also means we take on work that fits that shape, and say so when it doesn't.
